How to read these numbers (measurement honesty)

Every value on this page is a single-shot replay under variable machine load — the box ran at load average 6–16 throughout, with other benchmark work active. This is deliberately narrative-grade: it reconstructs the shape of the improvement arc, not a certifiable head-to-head. The campaign's certification protocol is different — paired, interleaved 5–7-run measurements on a quiet box, recorded in docs/HANDOFF.md. Where a single-shot cell disagrees with the paired record (e.g. a load-spiked pilot87/cre_b in the final commit, both IPM-routed and untouched by the Forrest-Tomlin ship; or a whole commit whose aggregate rose because its replay window was loaded), trust the paired record. HiGHS's qap12 (~103s) and qap15 (timeout) are its own pathological instances on this box. Load average per run is stored in the DB runs table. Data regenerable from assets/campaign.db via tools/replay_bench.py + tools/build_report_data.py.
