How to read these numbers (measurement honesty)

Every value on this page is a single-shot replay under variable machine load — the box ran at load average 6–16 throughout, with other benchmark work active. This is deliberately narrative-grade: it reconstructs the shape of the improvement arc, not a certifiable head-to-head. The campaign's certification protocol is different: three hosts, seven interleaved pairs per host, scored by the median host ratio and recorded in docs/HANDOFF.md. Where a single-shot cell disagrees with the paired record, trust the v3 board. HiGHS's qap12 (~103s) and qap15 (timeout) are its own pathological instances on this box. Load average per run is stored in the DB runs table. Data regenerable from assets/campaign.db via tools/replay_bench.py + tools/build_report_data.py.
